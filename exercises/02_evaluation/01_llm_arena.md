# LLM Arena

Evaluating Large Language Models (LLMs) is notoriously difficult. Automated metrics that score a response by its overlap with a reference text (such as BLEU and ROUGE) are cheap to run, but they often fail to capture the nuances of helpfulness, coherence, harmlessness, and overall quality perceived by humans.

As Andrej Karpathy, former Director of AI at Tesla and researcher at OpenAI, mentioned: *“I pretty much only trust two LLM evals right now: Chatbot Arena and the r/LocalLlama comments section”*. This highlights the value placed on real-user interaction and comparison for assessing LLM capabilities.

## Concept

The **Chatbot Arena** ([https://lmarena.ai/](https://lmarena.ai/)), often referred to simply as the LLM Arena, is a crowdsourced, open platform for evaluating LLMs based on human preferences. It's developed by the Large Model Systems Organization (LMSYS Org), originating from UC Berkeley.

**How it works:**
1.  Users interact with two **anonymous** LLMs side-by-side.
2.  They provide the **same prompt** to both models.
3.  Users **compare** the responses generated by the two models.
4.  Users **vote** for which model performed better based on their judgment (or declare a tie, or state both were bad).
5.  Only **after** voting the identities of the anonymous models are revealed.
6.  This large-scale collection of pairwise comparisons is used to generate a continuously updated **leaderboard** (often using an Elo rating system, similar to chess rankings) that reflects real-world user preferences regarding model performance.

The anonymity during comparison is crucial for avoiding bias towards specific model providers or popular names.

## Usage

Using the Chatbot Arena is straightforward and provides valuable insights into relative LLM performance. Here's a basic guide:

1.  **Step 1: Prompt**.
    *   Navigate to the Arena website ([https://lmarena.ai/](https://lmarena.ai/)).
    *   You'll typically see two chat windows labeled "Model A" and "Model B".
    *   Enter your query, instruction, or conversation starter into the input box. This prompt will be sent to both anonymous models simultaneously.

2.  **Step 2: Compare**.
    *   Wait for both Model A and Model B to generate their responses.
    *   Read and carefully compare the two outputs. Consider factors like:
        *   Helpfulness and relevance to your prompt.
        *   Accuracy and factuality.
        *   Clarity, coherence, and writing style.
        *   Completeness of the answer.
        *   Safety and harmlessness.

3.  **Step 3: Rate**.
    *   Below the responses, you'll find voting buttons.
    *   Choose the option that best reflects your assessment:
        *   `[A is Better]`
        *   `[B is Better]`
        *   `[Tie]`
        *   `[Both are Bad]`
    *   Click the corresponding button to cast your vote.
    *   **After voting**, the actual names of Model A and Model B will be revealed. Your vote contributes to their ranking on the leaderboard.
    *   You can then continue the conversation or start a new round with different anonymous models.

Trying out the Chatbot Arena yourself is the best way to understand its value and contribute to this community benchmark!

## Agent-Specific Benchmarks

Chatbot Arena measures **conversational quality**, how helpful and pleasant a model's answer is. For agents, this is not enough. When an agent is supposed to book a flight, a friendly wrong answer is still a failure.

Specialized benchmarks measure **task success**: did the agent actually complete the goal?

### Key Benchmarks

We won't use these in the notebooks, but they are worth knowing about and experimenting with on your own.

**[GAIA](https://huggingface.co/datasets/gaia-benchmark/GAIA)** (General AI Assistants)

GAIA tests agents on real-world questions that require chaining multiple tools, file reading, web search, code execution, to reach a single verifiable answer.

How to try it:
1. Browse the dataset on Hugging Face: `gaia-benchmark/GAIA`
2. Pick a Level 1 question (simplest tier) and try to solve it with your own agent
3. Compare your agent's answer against the ground truth annotation
4. The score is binary: exact match or not, no partial credit

**[WebArena](https://webarena.dev/)**

WebArena puts an agent in front of real web interfaces (a shopping site, a GitLab instance, Reddit) and asks it to complete tasks like *"find the cheapest red pen and add it to the cart"*. Success is measured by whether the action actually happened in the environment, not by what the agent said.

How to try it:
1. Follow the setup guide at [webarena.dev](https://webarena.dev/) to spin up the local web environments (Docker required)
2. Run a task against one of the environments with your agent
3. The evaluation script checks the environment state after the agent finishes, it either completed the task or it didn't

### Key Difference from Chatbot Arena

| | Chatbot Arena | GAIA / WebArena |
|---|---|---|
| What's scored | Human preference for the answer | Task completion (pass/fail) |
| What can fail silently | Wrong tool use, hallucinated results | Nothing, the task outcome is the ground truth |
| Eval unit | Single response | Full trajectory (all steps to reach a goal) |

A model that scores highly on Chatbot Arena might still fail at agentic tasks if it hallucinates tool outputs or selects the wrong API. Always evaluate agents on task success metrics, not just response quality.
